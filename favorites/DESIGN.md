# My favorites

A sparse page with a back link and a CSS-drawn classic Macintosh. Uses the existing site's IBM Plex Mono font and muted gray-green colors. The screen contains a classic file-browser window with three project links and an Apple icon. The project links open existing pages. The smiling Apple Mac icon toggles a speech bubble saying “Let’s talk about it.”, dismissible by clicking again, clicking elsewhere, or pressing Escape. A small balloon floats in the bottom-right of the desktop and opens the high-altitude balloon project (`projpages/project6.html`). Easter egg: typing "launch" or pressing the power light sends the balloon up while a small Telemetry window counts altitude to a random burst (30–34 km), then pops and drops a payload on a parachute. Clicking the landed payload opens a "Payload recovered" window with an egg; OK (or Escape) closes it and the balloon returns.

Local draft: `favorites/index.html`. The selections remain Rust deep learning, COOL compiler, and 3D printer restoration. The back link returns to the homepage. No site navigation, hero, or footer. Not published; remove noindex when ready for indexing.
